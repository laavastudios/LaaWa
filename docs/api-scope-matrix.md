# API Scope Matrix

| Capability | read | write | admin |
| --- | --- | --- | --- |
| Capability metadata | yes | yes | yes |
| Health | public | public | public |
| OpenAPI | public | public | public |
| Read messages | yes | yes | yes |
| Send/action messages | no | yes | yes |
| Read conversations | yes | yes | yes |
| Read contacts | yes | yes | yes |
| Realtime SSE | yes | yes | yes |
| Manage API keys | no | no | yes |

Account restrictions are an additional authorization boundary when configured on an API key.
