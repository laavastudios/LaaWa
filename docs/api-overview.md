# LaaWa Developer API

LaaWa's developer surface is versioned under `/api/v1` and is designed around standard HTTP, scoped bearer credentials, consistent response envelopes, and authenticated Server-Sent Events.

Use `/api/v1/openapi.json` as the machine-readable contract. Use `/developer/docs/guide` for the interactive quick start and `docs/api-reference.md` for the full written reference.
